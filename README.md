# Tmpmonkey

## How to use

### Before you start

You need to have Tampermonkey installed and working in your browser.

### Install a script
1. Find the script you want to use.
2. Open it and have a quick look at the code to see what it does.
3. Click the <kbd>Raw</kbd> button.
4. Tampermonkey should detect it and show you the install screen.
5. Click <kbd>Install</kbd>.

> [!WARNING]
> Always check the code before installing a userscript.
